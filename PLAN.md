# План монетизации публичных данных

## Концепция

Создание API-сервисов и инструментов парсинга, которые агрегируют разрозненные публичные данные из государственных источников и продают их в структурированном виде через API/подписку.

---

## Топ-ниши по формуле: (спрос × сложность доступа × отсутствие конкурентов)

### 1. Проверка ресторанных инспекций (Health Inspection Data)
- **Что:** Агрегация результатов санитарных проверок ресторанов со всех муниципалитетов
- **Почему:** НЕТ ни одного доминирующего провайдера. Данные разбросаны по тысячам county health departments
- **Покупатели:** Инвесторы в рестораны, коммерческая недвижимость, страховые компании
- **Ценообразование:** $100–500/мес за агрегированный доступ
- **Конкуренты:** Практически отсутствуют (только локальные приложения типа HDScores)

### 2. Верификация лицензий подрядчиков (Contractor License Verification)
- **Что:** Единый API для проверки лицензий подрядчиков по всем 50 штатам
- **Почему:** Каждый штат — отдельный licensing board, нет единого стандарта
- **Покупатели:** Страховые компании, генподрядчики, платформы типа Angi/HomeAdvisor
- **Ценообразование:** ~$0.75/запрос (ориентир — Cobalt Intelligence)
- **Конкуренты:** Cobalt Intelligence (начинают покрывать, но рано)

### 3. Нарушения строительных кодов (Code Violations)
- **Что:** Агрегация данных о нарушениях строительных, пожарных, экологических кодов
- **Почему:** Данные только на уровне муниципалитетов, агрегатора не существует
- **Покупатели:** Инвесторы в недвижимость (поиск distressed properties), страховые, арендодатели
- **Конкуренты:** Нет

### 4. Судебные записи штатов (State Court Records)
- **Что:** Оцифровка и структуризация дел из судов штатов (не федеральных)
- **Почему:** Многие суды до сих пор на бумаге или PDF. PACER берёт $0.10/стр
- **Покупатели:** Юрфирмы ($5K–50K/год), litigation finance фонды, страховые
- **Конкуренты:** UniCourt ($49–299/мес), Trellis (ограниченное покрытие)

### 5. Данные о лицензиях на алкоголь (Liquor License Data)
- **Что:** Заявки, трансферы, нарушения — из state alcohol control boards
- **Почему:** Обычно в PDF или базовых порталах без API
- **Покупатели:** Коммерческая недвижимость, дистрибьюторы алкоголя, инвесторы

## Международные рынки

### Россия/СНГ (наш основной фокус)
- **Данные ЕГРЮЛ/ЕГРИП** — выписки, ИНН, учредители
- **Данные Росреестра** — кадастровые номера, собственники, сделки
- **Госзакупки (zakupki.gov.ru)** — тендеры, контракты, участники
- **ФССП** — исполнительные производства
- **Арбитражные суды (kad.arbitr.ru)** — дела, решения

### Международные (высокий потенциал)
- **Индия** — Company registration (MCA), land records, court records
- **Бразилия** — CNPJ база, суды, нотариальные записи
- **Нигерия/Западная Африка** — Corporate Affairs Commission

## Техническая архитектура

```
┌─────────────────┐     ┌──────────────┐     ┌─────────────┐
│  Scrapers/ETL   │────▶│  Database    │────▶│  REST API   │
│  (Python)       │     │  (PostgreSQL) │     │  (FastAPI)  │
│                 │     │              │     │             │
│ • County sites  │     │ • Raw data   │     │ • Auth/Keys │
│ • State portals │     │ • Normalized │     │ • Rate limit│
│ • PDF parsers   │     │ • Indexed    │     │ • Billing   │
└─────────────────┘     └──────────────┘     └─────────────┘
```

### Стек
- **Парсинг:** Python (httpx, BeautifulSoup, Playwright для JS-сайтов)
- **PDF:** pdfplumber, camelot-py
- **БД:** PostgreSQL + Redis (кэш)
- **API:** FastAPI
- **Деплой:** Docker, Railway/Fly.io
- **Мониторинг:** Scrapy-подобные логи, алерты при поломке парсеров
