# WB Parser — Парсер Wildberries

Мощный парсер для анализа товаров, цен, остатков и отзывов на Wildberries.

## Возможности

- **Поиск товаров** — по ключевым словам с сортировкой и пагинацией
- **Информация по артикулам** — детальные данные по конкретным товарам
- **Парсинг отзывов** — все отзывы с оценками, текстом, плюсами/минусами
- **Анализ цен конкурентов** — группировка по брендам, мин/макс/средняя цена
- **Экспорт** — в Excel (.xlsx) и CSV
- **Поддержка прокси** — для обхода блокировок
- **Красивый вывод** — таблицы в консоли с цветами

## Установка

```bash
pip install -r requirements.txt
```

## Использование

### Поиск товаров
```bash
python main.py search "кроссовки" --pages 5 --sort popular --format excel
python main.py search "наушники" --sort priceup --format csv
```

Сортировка: `popular`, `priceup`, `pricedown`, `rate`, `newly`

### Информация по артикулам
```bash
python main.py product 12345678 87654321
```

### Парсинг отзывов
```bash
python main.py feedbacks 12345678 --pages 10
```

### Анализ цен конкурентов
```bash
python main.py prices "наушники" --pages 3
```

### С прокси
```bash
python main.py --proxy http://user:pass@host:port search "кроссовки"
```

## Данные, которые парсятся

| Поле | Описание |
|---|---|
| id | Артикул товара |
| name | Название |
| brand | Бренд |
| supplier | Продавец |
| price_basic | Цена без скидки |
| price_sale | Цена со скидкой |
| discount | Процент скидки |
| rating | Рейтинг (1-5) |
| feedbacks | Количество отзывов |
| total_stock | Общий остаток на складах |
| available_sizes | Доступные размеры |
| url | Ссылка на товар |

## Лимиты и рекомендации

- Задержка между запросами: 0.3с (настраивается в `config.py`)
- При блокировке (429/403) автоматические ретраи с экспоненциальной задержкой
- Рекомендуется использовать прокси при большом объёме парсинга
- WB мигрирует домены с `*.wb.ru` на `*.wildberries.ru` — эндпоинты в `config.py` легко обновить
